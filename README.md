## Descripción
App de Streamlit para el análisis estadístico de parcelas agrícolas.
Páginas: Inicio · Datos · EDA · Regresión (próximamente) · Series de tiempo (próximamente).

## Cómo ejecutarla
1. Abrir el repositorio en un Codespace.
2. Instalar las dependencias: `.venv/bin/pip install -r requirements.txt`
3. Iniciar la aplicación multipágina: `.venv/bin/streamlit run app.py`
4. En Codespaces, abrir la pestaña **Puertos**, buscar el puerto **8501** y
   seleccionar **Abrir en el navegador**.

La aplicación incluye las páginas **Inicio**, **Datos**, **EDA**, **Regresión**
y **Series de tiempo**. Las dos últimas presentan sus temas previstos; Series
de tiempo también incluye una vista previa de la precipitación mensual.
